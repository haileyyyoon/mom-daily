Put your photos in this folder! 📷

HOW TO USE:
1. Drag your image files (JPG or PNG) into this "photos" folder.
2. In messages.js, list the filename(s) for a day, for example:
       photos: ["beach.jpg"]
   or several:
       photos: ["beach.jpg", "sunset.jpg"]
3. Save messages.js and push (or edit on the GitHub website).

TIPS:
- Keep filenames simple: no spaces, all lowercase is easiest.
  Good:  us-at-graduation.jpg
  Avoid: Us At Graduation (1).JPG
- The name in messages.js must match the file name EXACTLY (including .jpg / .png).
- You can delete this README.txt whenever you like.
